# AquaLu

### A little desktop friend with one job: remind you to drink water.

[**Download AquaLu**](https://github.com/HydrateMe/aqualu-downloads/releases/latest)

AquaLu stays out of the way in your menu bar or system tray. When it is time for a
water break, AquaLu pops in with a bottle and waits for you to drink. You choose the
schedule, and snooze is there for the moments when you really need it.

No dashboards to maintain. No streaks to feel guilty about. Just a friendly nudge,
right when you asked for it.

## Choose your download

Go to the [latest release](https://github.com/HydrateMe/aqualu-downloads/releases/latest),
open **Assets**, and pick the file for your computer:

| Your computer | Download this file |
|---|---|
| Mac, Apple Silicon or Intel | `AquaLu_*_universal.dmg` |
| Windows 10 or 11 | `AquaLu_*_x64-setup.exe` |
| Ubuntu or Debian | `AquaLu_*_amd64.deb` |
| Fedora or RHEL | `AquaLu-*.x86_64.rpm` |
| Other 64-bit Linux | `AquaLu_*_amd64.AppImage` |

You can ignore files ending in `.sig` and the `latest.json` file. AquaLu uses those to
check updates safely inside the app.

## Install AquaLu

### Mac

1. Open the downloaded `.dmg` file.
2. Drag **AquaLu** into **Applications**.
3. Open AquaLu from the Applications folder.

Apple may block the first launch because the current build is not notarized. Open
**System Settings > Privacy & Security**, find the AquaLu message, and choose
**Open Anyway**. Only do this for a file downloaded from this official page.

### Windows

Open the downloaded `.exe` and follow the installer. Windows may show a SmartScreen
message while AquaLu builds its publisher reputation. Check that the file came from
this repository before continuing.

### Linux

Open the `.deb` or `.rpm` with your software installer. For the portable AppImage:

```bash
chmod +x AquaLu_*_amd64.AppImage
./AquaLu_*_amd64.AppImage
```

## Updates

AquaLu can tell you when a new version is ready. You decide whether to download and
install it, and automatic checks can be turned off in Settings.

## Your privacy

Reminders and preferences work locally on your computer. Connecting the AquaLu mobile
app is optional and stays off until you choose to enable cloud sync. Product analytics
is a separate choice and is also off by default.

Paired devices are shown by name and can be disconnected from either device.
